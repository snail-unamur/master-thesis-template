\chapter{Glossary}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\noindent \textbf{DevEx} Developer Experience

\noindent \textbf{FTP} File Transfer Protocol 

\noindent \textbf{REST} Representational State Transfer

\noindent \textbf{Test case} A set of conditions or variables under which a tester will determine whether a system under test satisfies requirements or works correctly. In this master thesis, a test case is a set of actions performed via the web interface of the application under test, and the expected result of these actions.
